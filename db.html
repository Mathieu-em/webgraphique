Design de base de données

1. Code DBML

Ce code définit trois tables et leurs champs, ainsi que les relations (clés étrangères) qui les lient.

Table personnes {
  nom_complet varchar
  age int
  nationalite varchar
  photo blob
}

Table films {
  titre varchar
  annee int
  realisateur varchar
  genre varchar
}

Table statistiques {
  film_titre varchar
  box_office float
  entrees_cinema int
  note_spectateurs float
}

Ref: films.realisateur > personnes.nom_complet
Ref: statistiques.film_titre > films.titre
