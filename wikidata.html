Exercice Wikidata - Top 100 des albums les plus vendus

Thème : Les albums de musique les plus vendus au monde

Code SPARQL de la requête :

#defaultView:BubbleChart
SELECT ?albumLabel ?sales WHERE {
  ?album wdt:P31 wd:Q482994;           # C'est un album de musique
         wdt:P2664 ?sales.             # Possède la propriété "unités vendues"
  
  SERVICE wikibase:label { bd:serviceParam wikibase:language "[AUTO_LANGUAGE],fr,en". }
}
ORDER BY DESC(?sales)               
LIMIT 100
